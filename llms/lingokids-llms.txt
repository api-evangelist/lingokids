# Lingokids

> Children's edutainment platform (Monkimun Inc. / Monkimun Labs S.L.) delivering an
> ad-free "Playlearning" experience of games, animated shows, podcasts and sing-alongs
> for children aged two to eight, across iOS, Android, Amazon and the web. Certified by
> the kidSAFE Seal Program (COPPA+). Lingokids publishes **no public API and no developer
> program** — api.lingokids.com is the private application backend and exposes no
> documentation, specification or discovery surface. This file is generated by the API
> Evangelist enrichment pipeline from the catalog profile at all/lingokids/apis.yml.

## APIs

No public API. Probed and confirmed absent as of 2026-07-19:
- https://developer.lingokids.com/ — does not resolve
- https://developers.lingokids.com/ — does not resolve
- https://docs.lingokids.com/ — does not resolve
- https://lingokids.com/developers — 404
- https://lingokids.com/api — 404
- https://api.lingokids.com/ — 200, returns an empty JSON object; /openapi.json, /swagger.json,
  /openapi.yaml, /graphql, /docs, /api-docs, /v1 and /asyncapi.yaml all return 404
